CarRec

CarRec recommends new cars sold in India from a knowledge base of 1,464 variants. The strongest evidence for 32.6% of the stored values is the June 2026 import, which recorded no source, and 772 of 1,464 variants have no price evidence newer than that import. A pipeline builds and updates the knowledge base, and a recommendation engine ranks cars from it. Each part has its own page.

The pipeline

A scripted run that reads two car sites and manufacturer brochures, links what they say to each variant, and writes new variants and blanks that pass four checks. Changes to values already stored wait for the owner.

How well the stored values are backed

Of 44,498 stored values, 14.9% rest on a maker's brochure, 44.4% on two or more listing sites, 4.5% on one listing site, and 32.6% only on the June 2026 import, which recorded no source address. 3.7% have no live evidence row at all.

What “verified” means here. A value is called verified here only if an independent check re-read its source and found the same value. That is true of 362 values, in a sample of 500 cells (audit run audit_2026-11-14): 362 of 404 decided cells agreed and 95 could not be reached. The other stored values have not been independently checked, and a sample audit is not a guarantee for any of them.
