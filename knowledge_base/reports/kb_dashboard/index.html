How to read this

Verified

A value is verified when it traces to a source the pipeline is allowed to trust: an OEM brochure page, or two sites that agree on the same variant. A separate model then re-reads a random sample of those sources to check the stored value. Verified does not mean certain. Sites can copy each other, and the Trust section shows what the re-check found.

Unknown

Unknown stays unknown. When no allowed source states a value, the cell is left empty and the reason is logged. It is never filled with a guess, an average or a value borrowed from a similar model. An empty cell is not a no: a feature the KB marks 0 was stated as absent, an empty cell was not stated at all.
